# Mantenimiento predictivo con machine learning

Demostración de Río Data Análisis: un modelo que estima la probabilidad de falla de un equipo y una ventana de tiempo, a partir de sus datos de operación y su historial de fallas. Como ejemplo se usan electrobombas sumergibles (ESP); la misma lógica aplica a otros equipos.

**Ver la demostración:** https://riodata.github.io/esp-prediccion-demo/

## Contenido

1. **La idea** — la ventana entre la operación normal y la falla.
2. **Las señales** — cómo cambian las variables antes de una falla simulada.
3. **El modelo** — datos de operación + historial de fallas → probabilidad y ventana.
4. **Calibración** — efecto del umbral de alerta.
5. **Tablero** — de la predicción a la decisión.
6. **Otros usos** — flotas de camiones, compresores, aerogeneradores, bombas de riego.
